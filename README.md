# Sudoku Android (C++ NDK)

Game Sudoku 9x9 untuk Android dengan engine generator, backtracking solver, dan validasi yang ditulis menggunakan C++17 melalui Android NDK + JNI.

## Fitur
- Generator puzzle acak dengan 3 tingkat kesulitan (Mudah, Sedang, Sulit)
- Deteksi konflik baris, kolom, dan kotak 3x3 secara real-time
- Fitur Hint dan hapus angka

## Build & Run
Buka folder project di Android Studio (pastikan NDK & CMake terpasang di SDK Manager) lalu jalankan ke emulator atau perangkat Android.
